주오맨 GOLF 휴대폰 홈 화면 바로가기(PWA) 적용 파일

대상 폴더:
GitHub > golfreservation > screengolf > public

업로드할 파일:
- index.html  (현재 파일과 교체)
- manifest.json
- pwa.js
- sw.js
- icon-192.png
- icon-512.png
- apple-touch-icon.png

현재 예약 사이트 주소:
https://golfreservation.pages.dev/

적용 후:
1. GitHub에 커밋합니다.
2. Cloudflare Pages 배포가 완료될 때까지 잠시 기다립니다.
3. 안드로이드 Chrome에서 https://golfreservation.pages.dev/ 접속
4. Chrome 우측 상단 ⋮ > '홈 화면에 추가' 또는 '앱 설치'
5. '주오맨 GOLF' 아이콘이 휴대폰 바탕화면에 생깁니다.
6. 아이콘을 누르면 주오맨 골프 예약 사이트가 바로 실행됩니다.

참고:
- Android에서 우선 지원하도록 구성했습니다.
- 아이폰은 홈 화면 추가 방식이 브라우저/버전에 따라 다르게 보일 수 있습니다.
- 예약 데이터는 캐시하지 않고 서버에서 그대로 불러오도록 서비스워커를 구성했습니다.
