# 주오맨 GOLF 업데이트 (2026-09-28)

## 바뀐 내용

1. **가입 간소화** — 아이디 · 비밀번호만 넣으면 신청. 닉네임 · 이름 · 연락처는 선택.
   마스터가 정회원/게스트로 **승인해야 로그인되는 절차는 그대로**.
2. **회비 (1년에 한 번)** — 회원 옆 "2026 회비" 버튼을 한 번 누르면 납부 표시, 다시 누르면 취소. 묻는 창 없음.
   게스트가 내면 자동으로 정회원. 강등은 드문 일이라 마스터가 등급 선택에서 직접.
3. **지난 설정 기억** — 새 일정을 만들면 지난 일정의 요일 · 시각 · 구장 · 모임 이름 · 참가비 · 방 수가 미리 채워짐.
   특별상도 지난번 상금 · 메모가 채워짐.
4. **로그인 유지** — 10년 유지, 쓸 때마다 자동 연장. 업데이트 배포 중에 앱을 열어도 로그아웃되지 않음.
5. **특별상 (홀인원 · 알바트로스)** — 마스터가 대회마다 상금을 걸고, 달성자 기록, 없으면 다음 일정으로 이월.
6. **Gemini** — 10/16 종료되는 2.5-flash 제거, 키 공백 자동 제거, 🔧 AI 연결 점검 버튼.
7. **reset.sql** — 실제 회원은 절대 건드리지 않도록 바꿈 (테스트 표시 계정만 정리).

## 적용 순서

1. GitHub → `screengolf` 폴더 안으로 들어가 → Add file → Upload files → 폴더 **안의 내용물** 드래그 → Commit
2. D1 콘솔 → `migrations/002_dues_jackpot.sql` 내용 붙여넣고 실행
   ("duplicate column name" 오류가 나면 이미 적용된 것이니 괜찮습니다)
3. **reset.sql은 실행하지 않습니다.**
4. 마스터 → 내 정보 → 🔧 점검하기 → ✅ 확인
